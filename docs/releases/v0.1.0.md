## Included scope

- one guided bootstrap installer and stable `porcupi` launcher;
- exact-commit selection of individual Pi resources through Pi's package lifecycle;
- exact source/path/digest Patch Selection Intent;
- one fixed deterministic Composition recipe and atomic apply;
- cheap fail-closed launch plus explicit complete verification;
- one retained local rollback Composition and process-lease-safe cleanup;
- optional reversible ownership of only `~/.local/bin/pi`; and
- receipt-proven conservative uninstall.

There is no release channel, background self-update, signing/delegation system, publisher authentication, provenance service, sandbox, generalized build adapter, arbitrary retention, automatic legacy adoption, Windows support, or Stock Pi fallback.

Exact Git identities, SHA-256 values, inventories, and receipts provide reproducibility and local-integrity evidence only. Selected code executes with the user's authority; use an external OS, VM, or container isolation boundary when required.
